Connect to Google Drive

This page shows a live, read-only view of today's collections — pulled straight from the same Drive folder the desktop app backs up to. Nothing can be edited here.

1. Sign in with Google

Uses your Google account only to read the backup folder — never to change anything in it.

2. Point it at your backup folder

Open Google Drive, go into the same folder the desktop app is connected to, and copy the ID from the address bar — the part after /folders/.

One-time setup, on your end

1Create a free project at console.cloud.google.com
2Enable the Google Drive API for that project
3Under Credentials, create an OAuth Client ID (type: Web application)
4Add this page's URL to Authorized JavaScript origins
5Paste that Client ID into GOOGLE_CLIENT_ID near the top of this file's code, before hosting it

This only needs doing once. After that, sign-in above is a normal one-tap Google login.
